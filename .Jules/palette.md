## 2024-05-18 - Render Progress Bar
**Learning:** Adding a progress indicator to a long-running async task (audio rendering) is a clear UX improvement. When writing in-place terminal updates in Rust, explicitly use the string escape sequences `\r` and `\x1b[2K` in your formatting macros (e.g., `eprint!("\r\x1b[2K...")`), ensure `std::io::Write` is imported, and explicitly call `std::io::stderr().flush()` to force the output to display immediately. Furthermore, throttle the refresh rate (e.g., using `std::time::Instant` with a 100ms interval) to prevent excessive I/O, which can significantly degrade rendering performance, and ensure a smooth user experience. Finally, conditionally apply ANSI escape sequences only when attached to a true TTY using `std::io::IsTerminal` to prevent log spam in CI environments.
**Action:** When implementing CLI progress updates or terminal UI refresh loops in Rust, follow these steps to ensure a smooth, performant, and safe user experience.
